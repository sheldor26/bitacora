# Learnings

> The counterpart to MISTAKES.md. When something works unusually well, the
> transferable part gets written down before it is forgotten.
>
> The test for an entry: would it change how you approach the *next* problem?
> If not, it is a changelog line, not a learning. Newest first.
>
> Add entries with: `node .bitacora/cli.mjs new learning "Title" --tags area`

### Example entry — delete this one once you have a real learning

**What worked.** Keeping this file separate from MISTAKES.md.

**Why it worked.** They are read at different moments. Mistakes are consulted
defensively, before touching a risky area. Learnings are consulted offensively,
when starting something new. Merging them means always reading twice as much
as you need.

**Reuse it when.** Any time you are tempted to merge two logs because they
"feel similar". Ask when each one gets read.
